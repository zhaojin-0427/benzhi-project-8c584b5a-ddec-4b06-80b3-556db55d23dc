# 古籍修复放行门禁

本项目是面向古籍修复室的单流程治理应用。它将受损页登记、版本化修复方案、材料相容性核验、模拟试样、专家复核、方案冻结和修复放行凭据串成一条可追溯链路，阻止未经验证的材料或工艺直接用于原件。

Go 服务同时提供原生 HTML、CSS、JavaScript 工作台和同源 JSON API。业务数据保存在本地 JSON Lines 事件日志中；每个事务带 `schemaVersion`、连续序号、前序哈希和自身哈希。查询投影通过临时文件 `Sync` 后原子 `Rename` 更新，启动时会校验事件链并在必要时重建投影。所有变更使用 `expectedVersion` 做乐观并发校验，并使用 `idempotencyKey` 保证安全重试。

工作台支持按馆藏编号或题名、责任修复师和状态组合筛选，显示各门禁状态待办计数；受损页可整批登记并生成页位、类型和严重度汇总。方案步骤必须关联损伤记录并覆盖全部高严重度损伤，整改版本还需逐项关闭材料阻断、失败试样和专家必改意见。相容性警示须记录控制措施后才能开始分轮试样；专家批准与最终放行分别绑定服务端重算的证据清单快照。

`GET /api/cases` 接受 `keyword`、`responsibleConservator`、`status`、`page` 和 `pageSize`，响应同时包含分页总数、状态计数及查询投影版本。损伤批次通过 `POST /api/cases/{caseID}/damages` 的 `records` 数组提交；方案、警示处置、试样轮次、复核与放行继续使用原有档案子资源入口。凭据验证会分项返回方案摘要、冻结状态、证据清单摘要、审计链头和签名结果。

## 构建与测试

要求 Go 1.22 或更新版本。

```bash
go build ./cmd/conservation
go test ./...
```

## 运行

默认仅监听高位回环地址 `127.0.0.1:19081`：

```bash
go run ./cmd/conservation
```

可通过参数指定其他回环端口：

```bash
go run ./cmd/conservation -addr=127.0.0.1:19123 -data=.data/conservation
```

也可以设置 `PORT` 为端口号；未显式传入 `-addr` 时，服务将监听 `127.0.0.1:<PORT>`。为避免意外暴露，服务拒绝 `0.0.0.0` 或其他非回环监听地址。打开服务根路径即可使用浏览器工作台。

## 有界自检

自检会创建临时数据目录，启动真实 HTTP 监听，通过同一 JSON API 完成建档、批量损伤登记、损伤覆盖方案编制、相容性核验、两轮试样、证据快照批准、证据锁定放行和凭据分项验证，然后主动关闭：

```bash
go run ./cmd/conservation -selfcheck -addr=127.0.0.1:19081
```

正常运行的数据目录默认为 `.data/conservation`，包含 `events.jsonl` 与 `projection.json`。放行后的方案及凭据不可修改；凭据验证同时检查方案摘要、冻结状态、门禁证据摘要、签名和审计链头。
